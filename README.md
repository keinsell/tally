# Counter

Counter is a desktop application with incrementation, decrementation and reset functionalities which purpose is to behold a number within state as application is running and is being used by user.

<p align="center">
  <img src="docs/assets/preview.png" alt="preview" />
</p>

## Rationale

Experimentation with [`blueprint-compiler`](https://gnome.pages.gitlab.gnome.org/blueprint-compiler/) and distribution of native desktop applications suitable for Gnome.
